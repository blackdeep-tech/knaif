## Two different developers

<CardGrid>
  <Card title="Putting NL on your own CLI">
    You have a CLI and want users to type sentences at it. You may never write a knaif
    skill. Start with the **knaif SDK** — it ships in the wheel, so `pip install knaif` is
    all you need.
  </Card>
  <Card title="Extending knaif">
    You want a new capability inside knaif itself — a skill others can install. Start with
    **Author a skill**, then evaluate it, then port it to native. Skill bundles live in the
    repo, so clone it first.
  </Card>
</CardGrid>
